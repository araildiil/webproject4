# Assignment #4 - Forms and Validation

**Student:** Arailym Amangeldi
**Group:** SE-2528

## Description

A multi-page website about HTML forms, Bootstrap form components and form validation
(HTML5 built-in validation and Bootstrap validation classes). Theme: minimal gray, white and black.

## Pages

| Page                      | Task   | Content                                                              |
| ------------------------- | ------ | -------------------------------------------------------------------- |
| index.html                | Task 0 | Simple contact form with labels                                      |
| validation.html           | Task 1 | HTML5 validation (required, type, minlength, maxlength, pattern)     |
| bootstrap-form.html       | Task 2 | Contact form with Bootstrap classes, grid, placeholders, helper text |
| bootstrap-validation.html | Task 3 | is-valid / is-invalid classes with feedback messages                 |
| registration.html         | Task 4 | Responsive registration form with full validation                    |

## Technologies

HTML5, CSS3, JavaScript, Bootstrap 5.3 (CDN)

## How to run

1. Clone the repository.
2. Open `index.html` in a browser.
3. Use the navbar to move between tasks.
